1. 資料與變數介紹

  • 資料說明：鳶尾花資料集（Fisher, 1936）：150 朵鳶尾花，3 個品種各 50 朵；依花萼與花瓣的長、寬（公分）預測花的品種。
  • 分析目的（要預測什麼）：預測 species——鳶尾花品種（預測目標）：setosa（山鳶尾）/ versicolor（變色鳶尾）/ virginica（維吉尼亞鳶尾），共 3 類：setosa（50 筆）、versicolor（50 筆）、virginica（50 筆）。這是一個分類問題（判斷依據見第 2 節）。
  • 用了哪些變數：4 個特徵（數值 4、類別 0）——sepal_length_cm（花萼長度，公分）；sepal_width_cm（花萼寬度，公分）；petal_length_cm（花瓣長度，公分）；petal_width_cm（花瓣寬度，公分）。
  • 資料共 150 筆、5 個欄位：目標 1 個（species）、特徵 4 個（數值 4、類別 0）、ID／排除 0 個。
  • 沒有 ID 類欄位，所有非目標欄位都當作特徵。
  • 完全重複的列 1 筆；常數欄位 無。

2. 判斷任務類型（分類 or 迴歸）

  • 判斷結果：分類（多類別分類（3 類））。理由：目標是文字／布林值，代表「類別」而非數量。
  • 多類別分類 = 預測「屬於哪一類」（超過兩類）；評估用 Accuracy、Macro-F1、混淆矩陣；切分要 stratify 保持各類別比例。
  • 判斷規則：文字／布林 → 分類；只有 2 種值 → 二元分類；整數且 ≤10 種值 → 多類別分類（需確認是否為計數/評分）；其餘數值 → 迴歸。任務類型決定了之後的模型（Classifier vs Regressor）、評估指標與切分方式，所以是第一步。

5. 資料切分

  • 為什麼要切分：模型在「看過的資料」上的分數一定偏樂觀（尤其是會記住資料的深樹）。必須留一份完全沒碰過的資料，才能估計上線後的真實表現。
  • 本次做法：先切出 25% 測試集（38 筆，鎖起來直到最後），剩下 112 筆訓練集再做 5 折交叉驗證（StratifiedKFold）：每次用 4 折訓練、1 折驗證，輪流 5 次取平均。模型用 CV 分數挑選，測試集只在最後報告一次。
  • 分類要 stratify：讓每份資料的類別比例都和全體相同，否則少數類別可能在某一份裡特別少，分數忽高忽低。
  • 切分後各類別筆數（訓練 / 測試）：setosa 38 / 12、versicolor 37 / 13、virginica 37 / 13；合計 112 / 38。各類別在訓練、測試中的比例都和全體一致（stratify 的效果）。
  • 避免洩漏：插補、編碼、特徵選擇都放進 Pipeline，在每一折只用該折的訓練資料 fit；不要在切分前對全部資料算平均數補值或標準化。
  • 其他切分情境：有時間順序 → TimeSeriesSplit（只能用過去預測未來）；同一客戶/病人有多筆 → GroupKFold（同一群不能同時出現在訓練與驗證）；Boosting 的 early stopping → 再從訓練集切出一小份驗證集；資料很少 → 用重複 CV（RepeatedKFold）讓估計更穩。

6. 模型訓練與比較（分類）

  • 比較三個樹模型：Decision Tree（單棵樹，可解釋）、Random Forest（多棵深樹平均，降方差）、Gradient Boosting（多棵淺樹接力修正殘差，降偏差）。三者使用相同的前處理 Pipeline 與相同的 CV 折，比較才公平。
  • 調參方式：每個樹模型都用 GridSearchCV 在訓練集上做 5 折交叉驗證，窮舉「模型參數與調參」表中的參數組合，選 CV Accuracy 最好的一組，再用整個訓練集重新訓練；最後只在測試集評估一次。註：調參後的 CV 分數因為是「挑過的最佳值」而略偏樂觀，所以最終以測試集確認。
  • ⚠ 最佳參數落在搜尋範圍的邊界：Gradient Boosting 的 max_depth=2。代表更好的值可能在範圍外，實務上應擴大該參數的搜尋範圍再跑一次。
  • 指標（多類別）：Accuracy（整體猜對比例，各類別筆數相同時最直觀，用來調參與選模型）、Macro-F1（各類別 F1 的平均，不受類別多寡影響）、AUC(ovr)（每一類對其他類的排序能力平均）。
  • 依 CV 選出最佳模型 Random Forest：CV Accuracy 0.964±0.033，測試集 Accuracy 0.895（38 筆猜錯 4 筆）、Macro-F1 0.897。
  • 訓練/測試 Accuracy 差距 0.105：有過擬合跡象。
  • 測試集只有 38 筆，猜錯 1 筆就差 0.026；多個模型分數接近時應視為平手，不要過度解讀。
  • 置換重要度（測試集）前五名：petal_length_cm（0.2210）、petal_width_cm（0.0184）、sepal_width_cm（-0.0237）、sepal_length_cm（-0.0263）。數值 = 打亂該欄後 Accuracy 變差多少；接近 0 或為負的欄位對模型幾乎沒貢獻。重要度不是因果。

參數中文意義與影響
